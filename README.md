Leonida Trophy Atlas — the best offline guide + tracker for all 55 GTA VI PlayStation 5 trophies: 55 original cited guides, a 7-stage roadmap to platinum, missable flags, and a spoiler-safe checklist that saves in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is plain static files under `app/` — no build step, no network. `main.ts` copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
